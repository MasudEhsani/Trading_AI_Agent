# data/

Everything the agent produces lives here, in two folders:

| Folder | What | In git? |
|---|---|---|
| `sample/` | Example output from a 6-month replay (generated by `scripts/generate_sample_data.py`) | yes |
| `live/` | **Your own runs**: `paper.db` (account, positions, order journal) and `reports/` from `--daily` | no (`.gitignore`) |

To put your live data somewhere else, set `TRADING_DATA_DIR=/some/folder`.

## How `sample/` was made

`python scripts/generate_sample_data.py` replays **130 trading days (2026-05-25 to 2026-11-20)**
through the project's real code: `market_data`, `indicators`, `risk` and the paper `broker`.

- **Prices are SIMULATED** (the reproducible random walk in `SimulatedMarket`), not real quotes.
- **No Claude, no API key.** The decisions Claude would propose are made by a simple
  rule-based stand-in:
  - buy ~1,800 EUR when SMA20 > SMA50, RSI < 70 and the 20-day change is positive
  - sell when SMA20 drops below SMA50, or at −8 % (stop-loss)
  - "add to winners" (+1,000 EUR) when a position is up 5 %+: a common instinct that the
    20 % position limit is there to stop
- Every proposal goes through the real risk rules. The ones that pass are approved, as if
  you had typed `/approve`; on the last day they would stay pending, like `--daily`.

Running the script again gives exactly the same files.

## What the sample shows

| | Stand-in strategy | Buy & hold |
|---|---|---|
| Return | −0.76 % | +0.01 % |
| Max drawdown | −5.57 % | −11.10 % |

- 18 orders filled, 7 completed round trips, 2 of them winners (28.6 %), 18 EUR in fees.
- **65 proposals blocked by the risk rules**, almost all "add to winner" orders that would
  have pushed one stock above 20 % of the portfolio.
- Trend-following on a random walk can't have an edge. Its signals arrive late, so it
  loses a little to whipsaws and fees. It held only about 40 % in stocks on average, which
  halved the drawdown. This is the baseline any smarter strategy (or Claude) has to beat, and why
  `performance vs. benchmark` should always be measured.

## Opening the database

```bash
sqlite3 data/sample/trading/paper_sample.db "SELECT id, symbol, side, qty, status, fill_price FROM orders;"
```
or with Python / pandas:
```python
import sqlite3, pandas as pd
con = sqlite3.connect("data/sample/trading/paper_sample.db")
pd.read_sql("SELECT * FROM orders", con)
```
